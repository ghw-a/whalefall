# AdminWhale · 鲸落后台皮肤

给 Typecho 管理后台换一身**鲸落**的皮：深色渐变顶栏、新拟态柔光卡片、胶囊按钮、深海风登录页，手机端也有完整适配。

> 纯 CSS 覆盖 + 一个 `<head>` 钩子，**不修改任何 Typecho 核心文件**。停用插件立刻还原原版，升级 Typecho 也不会被覆盖掉。

---

## 安装

1. 把 `AdminWhale` 整个目录上传到：

   ```
   usr/plugins/AdminWhale/
   ```

2. 后台「控制台 → 插件」，找到 **AdminWhale** → 点「启用」。

3. 进「设置 → 插件 → AdminWhale」调配色，保存。

> 如果后台菜单里没出现，检查目录名是否严格为 `AdminWhale`（大小写敏感），以及 `Plugin.php` 是否为 UTF-8 无 BOM。

---

## 设置项

| 设置项 | 默认 | 说明 |
|---|---|---|
| 启用后台皮肤 | 开启 | 关掉立刻恢复原版，不用停用插件 |
| 后台配色 | 跟随前台主题 | 海盐蓝 / 薄荷青 / 暖米绿 / 雾粉 / 跟随主题 |
| 登录页站名 | `鲸落` | 替换登录页上那个灰色的 Typecho 方标，留空则保留原字样 |
| 登录页深海背景 | 美化 | 关掉后登录页完全保持 Typecho 原样 |

**「跟随前台主题」** 会读取鲸落主题的「默认配色」设置。如果当前前台不是鲸落主题，或者没设过配色，就自动回落到海盐蓝。

## 移动端

| 断点 | 变化 |
|---|---|
| `max-width: 1024px` | 容器满宽，卡片内边距收紧 |
| `max-width: 860px` | 顶栏收成「菜单」汉堡 + 用户胶囊；写作页两栏塌成单列；编辑器工具栏横向滚动 |
| `max-width: 640px` | 文章表格只保留标题列，作者/分类/日期收起；筛选 tab 靠右 |
| `max-width: 575px` | 同步 Typecho 原生的底部固定栏高度（52px）与菜单展开方向 |
| `max-width: 520px` | 隐藏「登出」、按钮和字号再收一档 |

手机上的排行榜式表格会横向滚动，不会把内容压扁。

## 覆盖了哪些页面

- ✅ 登录页（深海渐变 + 毛玻璃卡）
- ✅ 控制台首页
- ✅ 文章管理 / 独立页面 / 分类 / 标签 列表
- ✅ 撰写文章（标题、编辑器、右侧选项栏）
- ✅ 设置页通用表单控件（输入框、下拉、复选框、多行文本）

评论管理、媒体库沿用通用卡片样式，细节尚未逐个打磨。

---

## 还原成原版

三种方式，任选：

1. 后台插件设置里把「启用后台皮肤」关掉；
2. 「控制台 → 插件」停用 AdminWhale；
3. 删掉 `usr/plugins/AdminWhale/` 目录。

---

## 已知限制

- **兼容 1.2.x / 1.3.x**。两版的区别在于：1.2 的表格外面包了一层 `.typecho-table-wrap`，1.3 直接是 `.typecho-list-table` 挂在 `.operate-form` 下；插件对两套结构都写了样式，表格卡片在哪个版本都不会丢。
- **只做了浅色后台**。深色模式还在计划里（P1）。
- 后台 DOM 的类名是 Typecho 内部约定，1.2 → 1.3 有极小概率调整；万一某块颜色没生效，通常是类名变了，改 1～2 条选择器即可，**不会影响后台功能**。
- CSS 只做视觉覆盖，没有改动任何表单结构、按钮行为和提交逻辑。
